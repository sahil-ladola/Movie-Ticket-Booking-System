# 🎬 Movie Ticket Booking System

Welcome to the **Movie Ticket Booking System** repository!  
A comprehensive, GUI-based application for managing movie ticket bookings, seat reservations, showtime selection, and invoicing — built with C# and Windows Forms.

---

## 🚀 Features

- **User Authentication:** Secure login for customers and administrators
- **Movie & Showtime Selection:** Browse movies, view available showtimes, and select preferred seats
- **Seat Reservation:** Real-time seat selection and reservation system
- **Booking Management:** Book tickets, generate invoices, and manage bookings
- **Admin Dashboard:** Manage movies, showtimes, and monitor bookings
- **Database Connectivity:** Uses SQL Server for robust, scalable data management
- **Event-driven Programming:** Responsive and interactive UI built with Windows Forms

---

## 🛠️ Tech Stack

- **Language:** C#
- **Framework:** Windows Forms
- **Database:** SQL Server
- **Other:** Event-driven programming, GUI application architecture

---

## 💡 How to Run

1. Clone the repository:
    ```bash
    git clone https://github.com/sahil-ladola/Movie-Ticket-Booking-System.git
    ```
2. Open with **Visual Studio**.
3. Restore NuGet packages if prompted.
4. Update database connection string in config files as per your SQL Server setup.
5. Build and run the project.
